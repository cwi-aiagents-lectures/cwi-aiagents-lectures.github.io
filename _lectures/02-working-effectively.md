## Overview

Getting good results from an agent is a skill. It depends on how you frame
the task, what context you provide, how you steer a longer piece of work, and
how carefully you check what comes back. This session is about harnessing
agents for real tasks.

## What we will cover

- **Task formulation.** Turning a vague goal into something an agent can
  complete reliably, including what "done" looks like.
- **Context.** What information to give an agent, and what happens when it
  has too little or too much.
- **Tool use.** How agents use tools such as the shell, files, search, and
  code execution, and how to set them up so this works for you.
- **Multi-step workflows.** Steering an agent through work that takes more
  than one step.
- **Human–agent interaction.** When to intervene, when to let it run, and how
  to recognise that it is going off track.

## Interactive component

Practical agent-based tasks and real-world workflow examples, many taken from
workflows we use ourselves.

## Between sessions

Try the techniques on a small task from your own research, programming,
studies, or a personal project. Note what worked and what did not; this feeds
directly into the final session.
