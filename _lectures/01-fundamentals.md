## Overview

AI agents now do much more than answer questions in a chat window. They plan
multi-step tasks, call tools, write and run code, search the literature, and
work inside real software environments. This first session explains what is
going on underneath, so that the rest of the course has something solid to
build on.

## What we will cover

- **From chat to agents.** How an LLM-based agent differs from conventional,
  single-turn chat use of a language model.
- **What makes a system "agentic".** Planning, acting, observing the result,
  and deciding what to do next.
- **The moving parts.** How agents interact with *models*, *tools*,
  *environments*, and *users*, and where each of these can help or get in the way.
- **Mental models.** Practical ways to think about what an agent can and
  cannot see, what it remembers, and why it behaves the way it does.

## Interactive component

Guided hands-on exercises with an AI agent. Bring a laptop with your agent of
choice installed and logged in (see [Before the session](#before-the-session)).

## Before the session

- Make sure you have access to an AI assistant **with agent capabilities**,
  for example Claude Code, ChatGPT Codex, or Gemini. Free tiers are often too
  limited for the longer exercises.
- Install it on the laptop you will bring and check that you can start a
  session in a local folder.
- No machine learning background is needed.
